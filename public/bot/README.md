# Discord Moderation Bot

Бот для модерации Discord сервера с веб-панелью управления.

## 🚀 Возможности

- ⏱️ **Таймаут** — выдача временного ограничения с готовыми пресетами
- 👢 **Кик** — выгон пользователя с сервера
- 🔨 **Бан** — полная блокировка пользователя
- 🗄️ **База данных** — SQLite для хранения логов и настроек
- 🌐 **Веб-панель** — управление ботом через браузер

## 📋 Требования

- Python 3.14+
- Токен Discord бота

## 🛠️ Установка

```bash
# 1. Клонируйте проект
cd bot/

# 2. Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Настройте .env файл
cp .env.example .env
# Отредактируйте .env и вставьте ваш токен

# 5. Запустите бота
python main.py
```

## 📁 Структура проекта

```
bot/
├── main.py          # Основной файл бота
├── config.py        # Конфигурация
├── database.py      # Работа с БД
├── requirements.txt # Зависимости
└── .env.example     # Пример .env файла
```

## 🎮 Команды бота

| Команда | Описание | Права |
|---------|----------|-------|
| `/timeout` | Выдать таймаут | Moderate Members |
| `/kick` | Кикнуть пользователя | Kick Members |
| `/ban` | Забанить пользователя | Ban Members |

## 🗄️ База данных

Бот использует SQLite для хранения:
- Логов модерации
- Предупреждений пользователей
- Настроек серверов
- Активных таймаутов

## 🌐 Веб-панель

Веб-интерфейс позволяет:
- Просматривать статистику
- Управлять модерацией
- Просматривать логи
- Настраивать бота
